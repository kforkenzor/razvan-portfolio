## Overview

An operational dashboard for a municipal traffic authority. One view covers the city's roads,
intersections, traffic signs and signal infrastructure; live IoT telemetry drives a map overlay,
per-road congestion levels and an incident queue, with signal-timing control, maintenance and
road-works tracking, system-health monitoring and role-based access for operator teams alongside
it. Cyber Koala dates the build 2024–2025.

I built this as a contract developer for Cyber Koala, the agency that took the project, working
across the whole stack: the Next.js operator interface, the Node.js API behind it, the PostgreSQL
model, and the realtime path carrying IoT telemetry to the screen. It was not a solo build — the
codebase was shared, and this page does not claim otherwise.
